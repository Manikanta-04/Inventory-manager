## 🌟 Overview

**STOCKR** is a fully client-side inventory management dashboard built into a single `index.html` file. No frameworks, no installs, no backend — just open it and go. Designed with a clean dark UI, STOCKR gives you everything you need to manage your stock visually and efficiently.

---

## ✨ Features

| Feature | Description |
|---|---|
| 📊 **Live Charts** | Real-time charts that update as you manage your inventory |
| 🎯 **Animated Stats** | Dynamic stat cards with smooth number animations |
| 🛠️ **Full CRUD** | Create, Read, Update, and Delete inventory items effortlessly |
| 🚨 **Smart Stock Alerts** | Automatic low-stock warnings to keep you ahead |
| 🍩 **Category Donut Viz** | Visual breakdown of inventory by category |
| 🔍 **Real-Time Search** | Instant search filtering across all inventory items |
| 🌑 **Dark Theme** | Eye-friendly dark UI — looks great day or night |
| 📁 **Single File** | Everything packed into one standalone HTML file |

## 🚀 Getting Started

No installation required. Seriously.

```bash
# Clone the repository
git clone https://github.com/manikanta-04/stockr.git

# Navigate into the project
cd stockr

# Open in your browser
open index.html
```

Or just **download `index.html`** and double-click it. That's it.

---

## 🖥️ Usage

1. **Add Items** — Click the **Add Item** button and fill in the product details (name, category, quantity, price).
2. **Edit / Delete** — Use the action buttons on each row to update or remove items.
3. **Search** — Type in the search bar to instantly filter items by name or category.
4. **Monitor Alerts** — STOCKR automatically highlights items that fall below the minimum stock threshold.
5. **View Analytics** — Check the live charts and donut visualization for a quick overview of your inventory health.

## 🚨 Smart Stock Alerts

STOCKR automatically flags items when stock drops below a defined threshold. Alerts are color-coded:

- 🟢 **In Stock** — Quantity is healthy
- 🟡 **Low Stock** — Quantity is below the minimum threshold
- 🔴 **Out of Stock** — Quantity is zero
